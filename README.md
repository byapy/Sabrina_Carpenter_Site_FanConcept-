# Sabrina Carpenter Fan Concept

This project is a fan concept website inspired by Sabrina Carpenter. So far, I have created the main page with a visual design centered around a background image, a top navigation bar, a featured message about her music, and a decorative play button.

I have also added a footer with links to her social media accounts and a disclaimer to clarify that this is a fan-made project and is not affiliated with her official team.

At the moment, I am mainly working with HTML and CSS, using Bootstrap for some resources on the site.
